# Reisemodell: die Reise als geprüfte Wahrheit

Die Beschreibung für Nutzer:innen steht auf der Webseite jeder Frieda-Instanz unter `/info/funktionen/wahrheit/`, auf Deutsch und Englisch, mit Bildern aus den Beispielreisen (Texte in `engine/texte_<sprache>.py` unter `info.bereich.wahrheit.…`, Aufbau in `INFO_UNTERSEITEN` in `engine/anmeldung.py`).
