## Was gebaut wird

Betriebsmeldungen landen künftig in einer neuen privaten Ablage, sodass die alte Reisen-Ablage archiviert werden kann.

## Definition of Done

Eine Probemeldung erscheint in der neuen privaten Ablage, die sechs offenen Aufgaben sind übertragen oder begründet geschlossen, die alte Ablage ist archiviert.

## Wie geprüft wird

Automatische Tests sichern Doku, Texte und Meldeziel gegen Rückfall; Probemeldung, Übertragung und Archivierung werden nur von Hand im Issue nachgewiesen.

## Kritische Anmerkungen

- Zusätzlich zum Verlangten: Sitzungsskripte der Infrastruktur und Texte in der Software werden mit angepasst.
- Überholte Issues werden geschlossen statt übertragen; der Tech Lead entscheidet das je Fall.
