## Was gebaut wird

Die Ablehnungsmeldung für eine leere Option nennt künftig alle fünf möglichen Inhalte, auf Deutsch und Englisch.

## Definition of Done

Eine leere Option wird abgelehnt, und die Meldung nennt in beiden Sprachen Unterkünfte, Strecken, Aufenthalte, Orte und Folge.

## Wie geprüft wird

Ein Test prüft, dass beide Sprachtexte alle fünf Sorten nennen; dass das Annahmeverhalten unverändert bleibt, prüft er nicht eigens.
